靶场怎么搭：三条路，我踩过的坑

DATE 2026-06-01 1174 字 · 约 3 分钟读完 FILE 2026-06-01-lab-setup.md

刚开始练的时候，我花在装环境上的时间比写 payload 多得多。DVWA、sqli-labs、VulnHub 这三种我都折腾过，各有各的麻烦。先把结论放前面：

方式 上手难度 适合谁 主要麻烦
Docker 低 所有人，首选 镜像拉取慢；Windows 得开 WSL2
phpstudy 中 习惯 Windows，想顺便摸 PHP 配置 PHP 版本是新老代码的雷
VulnHub 低 想练完整链路（连信息收集、提权一起） 网卡模式选错就白扫

三种可以都留着。DVWA 和 sqli-labs 用来练单个漏洞点，VulnHub 用来练一整套流程。

Docker

前提是本机装好 Docker Desktop，Windows 上还得把 WSL2 开起来。

BASH7 行
# DVWA
docker pull vulnerables/web-dvwa
docker run -d --name dvwa -p 8081:80 vulnerables/web-dvwa

# sqli-labs
docker pull acgpiano/sqli-labs
docker run -d --name sqli -p 8082:80 acgpiano/sqli-labs

浏览器打开 http://127.0.0.1:8081，账号密码是 admin / password。

第一次进去基本都是懵的，因为有几个默认设置会挡住你。

DVWA 要先点左边的 Setup / Reset DB，再点 Create / Reset Database。跳过这一步，所有模块都会报数据库连不上。

默认安全等级是 impossible。得先去 DVWA Security 里改成 low。我第一次不知道这事，还以为是自己的 payload 写错了，在那改了半天。

镜像拉不动是纯粹的网速问题。换个时间段，或者配个镜像加速器，别去怀疑 Docker 装坏了，它没坏。

容器一停，里面的数据就没了。想留下自己的记录就挂个卷：

BASH1 行
docker run -d --name dvwa -p 8081:80 -v dvwa-db:/var/lib/mysql vulnerables/web-dvwa

日常用到的就这几条：

BASH5 行
docker ps -a              # 看所有容器
docker stop dvwa          # 停
docker start dvwa         # 再开
docker rm -f dvwa         # 删掉重来
docker logs dvwa          # 起不来的时候看这里

phpstudy

把 DVWA 或 sqli-labs 的源码丢进 phpstudy 的 WWW 目录，建个站点指过去，就好了。好处是能顺手改 PHP 配置、看错误日志。Docker 里改这些要先进容器，麻烦一些。

但有两个坑是真会卡人的。

PHP 版本是第一个。sqli-labs 那套老代码里全是 mysql_* 系列函数，这些函数在 PHP 7.0 就被彻底删掉了。用 phpstudy 自带的 PHP 7.x 打开，满屏都是 Call to undefined function mysql_connect()。

三个办法：

  1. 在 phpstudy 里切一个 PHP 5.6 出来（最省事）
  2. 换 sqli-labs 的 mysqli 分支
  3. 回去用 Docker 版，人家镜像里已经配好了

麻烦的地方在于 DVWA 新版要求 PHP 7 以上，反而不能用 5.6。两个靶场对 PHP 版本的要求正好相反，这就是我不建议只留 phpstudy 一个环境的原因。

端口占用是第二个。phpstudy 装完可能自带几个站点，80 被占了之后你新加的站点会静默地起不来，不报错，很安静。先看一眼：

BASH1 行
netstat -ano | findstr :80

VulnHub

DVWA 是给你一个洞让你打，VulnHub 是给你一台机器让你自己找。后者更接近真实的东西，也更磨人。

流程是这样：

  1. 在 vulnhub.com 下 .ova / .vmdk
  2. 用 VMware 或 VirtualBox 导入
  3. 网卡模式改成「仅主机（Host-Only）」或者 NAT
  4. 扫网段找到它的 IP，开始打

网络模式是唯一一个能让人白干半天的坑。默认的桥接模式在某些校园网、宿舍网里拿不到 IP；就算拿到了，如果网络做了客户端隔离，攻击机和靶机还是互相看不见。症状就是扫了半天网段什么都没有。

判断方法：在靶机控制台敲一下，看有没有拿到地址。拿不到就换 Host-Only，然后给两张网卡配同一网段，比如 192.168.56.0/24。

入门靶机推荐这几个，按由易到难：

  • Metasploitable 2：洞多到离谱，适合熟悉工具链
  • Kioptrix 系列：老，但漏洞点很典型
  • DC 系列：完整的 Windows AD 场景，练提权很好用
  • HackTheBox / TryHackMe：不是本地靶机，但题面和引导做得细

在哪练

上面三种方式有个共同点：靶场都在你自己的机器或者你自己的局域网里。这是判断「能不能动手」的唯一标准。

「这个站看起来没什么人用」「我只是扫个目录不算攻击」，这些都不算理由。《网络安全法》第二十七条写的是「不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动」，扫描本身就落在「干扰」的射程里。学校的域名、别人的站点、SRC 范围外的资产，都不要碰。

合法能练的就这几类：

  • 自建靶场，也就是本文这些
  • CTF 比赛的靶机，有明确授权
  • SRC 平台范围内的资产，范围就是授权
  • 自己买的云服务器

把线画清楚，剩下的就能放开折腾了。

搭好之后

建议顺手做一件事：把「怎么跑起来」写成自己的笔记。

你会重装系统，会换电脑，会过半年忘记镜像名。到时候最不想干的事，就是重新查一遍怎么建数据库。
