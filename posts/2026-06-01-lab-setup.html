把 DVWA 和 sqli-labs 跑起来：三条路，各自的坑

DATE 2026-06-01 1111 字 · 约 3 分钟读完 FILE 2026-06-01-lab-setup.md

先说结论

方式 上手难度 适合谁 主要麻烦
Docker 低（装完 Docker 就完事） 所有人，首选 镜像拉取慢；Windows 要 WSL2
phpstudy（Windows） 中 习惯 Windows、想顺便摸 PHP 配置 PHP 版本兼容是老代码的雷
VulnHub 虚拟机 低 想练完整渗透链（含信息收集、提权） 网卡模式选错就白扫

三条路不冲突。DVWA / sqli-labs 练单点漏洞，VulnHub 练完整链路，建议都留着。

一、Docker：最省事

前提是本机装好 Docker Desktop（Windows 需要开 WSL2）。

BASH7 行
# DVWA
docker pull vulnerables/web-dvwa
docker run -d --name dvwa -p 8081:80 vulnerables/web-dvwa

# sqli-labs
docker pull acgpiano/sqli-labs
docker run -d --name sqli -p 8082:80 acgpiano/sqli-labs

浏览器打开 http://127.0.0.1:8081，账号密码是 admin / password。

坑一：第一次进去不是直接能用。 DVWA 要先点左侧的 Setup / Reset DB，再点 Create / Reset Database，否则所有模块都会报连不上数据库。

坑二：默认安全等级是 impossible。 进去先在 DVWA Security 里改成 low，不然你会以为自己的 payload 写错了。

坑三：镜像拉不动。 这是纯粹的网速问题，换个时间段或者配一下镜像加速器，别去怀疑 Docker 装坏了。

坑四：容器一停数据就没了。 想保留自己的记录就挂个卷：

BASH1 行
docker run -d --name dvwa -p 8081:80 -v dvwa-db:/var/lib/mysql vulnerables/web-dvwa

常用操作：

BASH5 行
docker ps -a              # 看所有容器
docker stop dvwa          # 停
docker start dvwa         # 再开
docker rm -f dvwa         # 删掉重来
docker logs dvwa          # 起不来的时候看这里

二、phpstudy：Windows 上最直观

把 DVWA 或 sqli-labs 的源码丢进 phpstudy 的 WWW 目录，建个站点指向它，就完事了。好处是你能顺手改 PHP 配置、看错误日志——Docker 里改这些要进容器，麻烦。

但这条路有两个真实的雷：

雷一：PHP 版本。 sqli-labs 的老代码大量使用 mysql_* 系列函数，这套函数在 PHP 7.0 里已经被彻底移除。你用 phpstudy 自带的 PHP 7.x 打开，只会看到一片 Call to undefined function mysql_connect()。

三个选择：

  1. 在 phpstudy 里切一个 PHP 5.6 的版本（最省事）
  2. 换 sqli-labs 的 mysqli 分支
  3. 干脆回去用 Docker 版（它的镜像里已经配好了）

DVWA 新版要求 PHP 7 以上，反而不能用 5.6，两个靶场对 PHP 版本的要求是相反的——这就是为什么我不建议只靠 phpstudy 一个环境。

雷二：端口占用。 phpstudy 装完可能自带几个站点，80 被占了之后你新加的站点会静默地起不来。先确认端口：

BASH1 行
netstat -ano | findstr :80

三、VulnHub：练真正的渗透链

DVWA 是「给你一个洞，你去打」；VulnHub 是「给你一台机器，你自己找洞」。后者更接近真实场景，也更练人。

流程：

  1. 在 vulnhub.com 下 .ova / .vmdk
  2. 用 VMware 或 VirtualBox 导入
  3. 网卡模式改成「仅主机（Host-Only）」或 NAT
  4. 扫网段找到它的 IP，开始打

唯一但致命的坑：网络模式。 默认的桥接模式在某些校园网/宿舍网里会拿不到 IP，或者因为网络做了客户端隔离，你的攻击机和靶机根本互相看不见——症状就是扫了半天网段什么都没有。

判断方法：在靶机控制台敲一下看它有没有拿到地址；拿不到就换成 Host-Only，并给两个网卡配同一网段（比如 192.168.56.0/24）。

入门靶机推荐（由易到难）：

  • Metasploitable 2 —— 洞多到离谱，用来熟悉工具链
  • Kioptrix 系列 —— 老，但漏洞点很典型
  • DC 系列 —— 完整的 Windows AD 场景，练提权很合适
  • HackTheBox / TryHackMe —— 不是本地靶机，但题面和引导做得更细

四、几条关于「在哪练」的话

上面三种方式有个共同点：靶场跑在你自己的机器或者你自己的局域网里。这是判断「能不能动手」的唯一标准——不是「这个站看起来没什么人用」，也不是「我只是扫个目录不算攻击」。

《网络安全法》第二十七条写的是「不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动」，扫描本身就在「干扰」的射程里。学校的域名、别人的站点、SRC 范围外的资产，统统不要碰。

练手的合法出口就这几类：

  • 自建靶场（就是本文这些）
  • CTF 比赛的靶机（有明确授权）
  • SRC 平台范围内的资产（范围就是授权）
  • 自己买的云服务器

这条线画清楚了，剩下的都能放心折腾。

最后

靶场搭好之后，建议立刻做一件事：把「怎么跑起来」写成自己的笔记。

因为你会重装系统、会换电脑、会过半年忘记镜像名。到时候最不想干的事，就是重新查一遍怎么建数据库。
