我是谁

在校学生，信息安全专业方向，学校安全协会成员。日常在 CTF、渗透测试、漏洞挖掘 之间来回折腾，也参加一些社团的招新和运营工作。

建这个站的目的很单纯：把每次「搞通了」的瞬间留下来。 踩过的坑、绕过的弯、最后想明白的那句话，不写下来过两个月就全忘了。

这里写什么

  • CTF 复盘：赛题思路、卡点、赛后补的解法，不美化过程。
  • 渗透测试笔记：靶场练习、工具链调优、报错排查路径。
  • 逆向与二进制：静态分析、动态调试、保护绕过。
  • 等保合规：把标准条款和实际测试动作对应起来。

这里不写什么

不写自己没跑通的东西，不写从别处抄来没验证过的结论。宁可少一篇， 也不放一篇「看起来对」的文章。

所有内容仅用于授权范围内的安全测试与学习研究。 对未授权目标进行扫描、爆破、入侵，在《网络安全法》下属违法行为—— 练手请用 DVWA、sqli-labs、VulnHub 或自建 Docker 靶场。

技术上的事

整站是纯静态的，跑在 GitHub Pages 上。生成器是自写的 tools/blog.js，零依赖的 Node 脚本；样式手写在 p5r.css 里；交互是原生 JS，没有用框架。 Markdown 解析和代码高亮用的是本地化的库，整站零外部请求。

能用浏览器原生能力的地方就没用 JS 去模拟：转场是 View Transitions，搜索面板用 <dialog>， 阅读设置用 Popover，进度条走滚动驱动动画， 主题色用 light-dark() 一套变量管两种模式。 每一项都留了降级路径，老浏览器只是少一点动效，不会坏。

界面照着《Persona 5 Royal》做的：红黑白三色、斜切色块、粗斜体标题、 转场擦除。想了解具体怎么实现的，看 这篇设计笔记。
